## Research should keep moving when the researcher steps away

I am an independent researcher with one 24 GB GPU. My bottleneck is not one missing answer; it is
the hundreds of research actions between a question and an experiment worth running. Search the
nearest work. Check the implementation. Attack the mechanism. Run the cheap counterexample.
Preserve the failure. Decide what deserves the GPU next.

Cloud Research turns that friction into a persistent expert panel. I write one research contract
in a GitHub Issue and add `cloud-research`. A signed Cloud Run event starts a Google ADK Director on
Gemini 3.7 Flash. It recruits a user-defined panel—Scout, Mechanist, Probe, Skeptic, Writer, and
Explainer—in whatever order the evidence demands. Firestore records what happened; Writer returns
a GitHub research branch; Gemini Live lets me debrief the lab when I return.

There is no scripted scientific state machine. Cloud Run owns lifetime, Firestore owns facts, and
Gemini owns research judgment. The human remains the PI.

The most important result was not a perfect score. Three cross-domain Cloud Run Jobs completed,
but a source audit found that only 23 of 24 unique URLs resolved. We kept the failed citation in the
public evaluation. A research agent should make its uncertainty inspectable, not merely sound
confident.

Public repository: https://github.com/plbbl/cloud-research
